# Finite set diagrams

Set applets follow the tree guide's open notebook layout: buttons above, a
picture left, and the current explanation right. On phones they stack. They
have no enclosing border, card background, or visible app title. Irregular
contours adapted from the author's Excalidraw sources contain the original
character and object illustrations. Model spaces use little globe icons with
mathematical labels.

Selections shade and hatch whole regions and outline the relevant members.
Color is supplementary to hatching and dashed selection rings. Hover and focus
preview a selection; activation retains it. Pictures appear within explanation
sentences, without a separate row repeating the selection. An accessible spoken
result and expandable text alternative accompany the diagram. All prose pictures
have transparent backgrounds and theme-aware ink. Scene colors use the `--set-*`
tokens, which adapt to light and dark themes.

## Inference overviews

Inference overviews are open displays, with each rule beside its name and
explanation. Only the inference bar is ruled. They share the existing inference
renderer and remain side by side on small screens when space permits.
