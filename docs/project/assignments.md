# Annual assignments

Assignment sources and their original backup live outside this repository in
`../2026-2027/assignments/`. That standalone Pandoc/XeLaTeX package produces
three student handouts and a separate solutions and grading PDF for the teaching
team. Its README documents editing and rebuilding. Assignment pages, their
dedicated template, and their stylesheet are no longer part of the website.

Run `python3 build.py --check` from that directory to build the PDFs. See
[Authoring tools](../technical/authoring-tools.md) for how this replaced the
former hidden Hugo Assignments section.
